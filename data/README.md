# Dataset

## Overview

This project uses the **MILE (Microarray Innovations in Leukemia)** dataset.

- **Dataset:** GSE13164
- **Platform:** GPL7473
- **Source:** NCBI Gene Expression Omnibus (GEO)
- **Samples:** 1,152
- **Classes:** 18 diagnostic classes (17 leukemia subtypes and one healthy bone marrow control group)

## Data Access

The dataset is automatically downloaded from NCBI GEO using the `GEOparse` package.

No raw microarray data are redistributed in this repository. Users should obtain the dataset directly from GEO in accordance with the GEO data usage policies.
